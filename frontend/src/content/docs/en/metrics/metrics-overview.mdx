## What the metrics page answers

Metrics is for operational insight after work already exists. It helps answer:

- how much work is open
- what is completed versus overdue
- how delivery is trending
- how work is distributed by label, priority, and project

## Common panels

Depending on available data, the metrics view includes areas such as:

- total tasks
- completed work
- overdue work
- average cycle time
- velocity over recent days
- label and priority distribution
- project breakdown
- team performance

## How to use metrics responsibly

Metrics should guide decisions, not replace conversation. Use them to spot patterns and ask better questions.

Examples:

- Why is one project carrying most overdue work?
- Why is critical priority growing faster than completion?
- Which team members are carrying unusual load?

## Good review rhythm

- daily: overdue and near-term delivery
- weekly: velocity and project completion movement
- monthly: recurring bottlenecks, labels, and trend shifts
