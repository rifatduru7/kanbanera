## What lives in Settings

Settings and profile surfaces cover personal workspace preferences and account security.

## Profile basics

Users can update personal details such as:

- first and last name
- profile identity shown inside the workspace

## Interface preferences

The current profile experience includes:

- theme selection
- language selection
- email notification preference
- browser push notification preference

## Security controls

Security-related actions include:

- password change
- two-factor authentication setup
- email-based or app-based verification paths where available

## Notification behavior

Notifications are split between in-app visibility and preference-controlled delivery. Use settings to decide whether email or browser push should remain active for your account.

## Destructive action

Account deletion exists in the danger zone and should be treated as irreversible.

<WarningCallout title="Before deleting an account">
Make sure ownership, admin access, and project responsibility have been transferred where needed. Deleting an account can break team continuity.
</WarningCallout>
