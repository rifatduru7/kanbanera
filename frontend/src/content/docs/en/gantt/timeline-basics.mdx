## What Gantt adds beyond the board

Gantt answers scheduling questions that are hard to see on the board:

- which tasks are clustered in the same period
- which items are already overdue
- how dates shift when work moves
- how work looks when grouped by project, assignee, status, or priority

## Timeline controls

The current view supports multiple zoom levels:

- day
- week
- month

Use day when validating short execution windows, week for active delivery planning, and month for broader roadmap-style review.

## Grouping options

You can group Gantt tasks by:

- project
- status
- assignee
- priority

Grouping helps you turn one timeline into multiple planning lenses without duplicating the work.

## Direct date updates

When timeline interactions are enabled, changing a task on the chart updates the task’s date range in the underlying data flow. Use that carefully and confirm the effect on the task detail afterwards.

## Good use cases

- sprint or release planning
- weekly schedule validation
- spotting overdue work quickly
- reviewing one person’s due-date load

## Calendar vs Gantt

Calendar is better for day and week slot awareness.

Gantt is better for continuous timeline understanding and grouped schedule review.
