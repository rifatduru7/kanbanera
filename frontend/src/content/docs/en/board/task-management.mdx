## Why the board is the operational center

Board is where teams spend most of their execution time. It combines status visibility with fast updates, which makes it the right place for everyday task movement.

## Core board actions

From the board you can:

- switch projects
- create tasks in specific columns
- move tasks between columns
- filter by status, assignee, priority, label, and date
- open archived tasks
- open automation rules
- manage columns and project settings

## Columns and WIP control

Columns represent workflow states. A good board uses a small number of meaningful columns.

Where supported, WIP limits help teams spot overload before work stalls.

## Filtering and focus

Filters are most useful when the board starts to carry real volume. Use them to answer concrete questions such as:

- what is assigned to me
- what is overdue
- what is high priority
- what is blocked in a specific status

Do not over-filter by default. The board should stay understandable even without a heavy query layer.

## Creating tasks from the board

The best task titles are short, action-oriented, and specific enough to survive outside the original conversation.

Examples:

- Prepare approval deck for client review
- Fix upload error for large attachments
- Add onboarding reminder notification

## Archived tasks

Archived work should be treated as inactive history, not active inventory. Use the archive drawer to review or recover work when needed.

## Board-level automation entry points

Automation rules are close to the board because they act on board events. Add them only after the manual workflow is stable enough to automate confidently.
