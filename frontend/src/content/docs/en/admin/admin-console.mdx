## Who this page is for

The admin console is for workspace-level administrators, not regular project users.

## Main admin areas

The admin surface includes tabs such as:

- overview
- system
- users
- projects
- activity log
- settings

## What admins can do

Depending on the tab, admins can:

- inspect platform usage and health
- manage users
- manage or remove projects
- review activity logs
- export CSV data
- configure maintenance mode and registration defaults
- manage SMTP and third-party integration settings

## Maintenance mode

Maintenance mode is a high-impact platform control. Use it only when operational work requires broad user restriction.

## Data exports

Exports are useful for audits, offline analysis, and reporting. Treat them as sensitive data because they can contain operational or identity information.

## Recommended safeguards

- keep the number of admins small
- review destructive actions carefully
- test SMTP and integrations intentionally
- use activity logs to verify major admin changes
