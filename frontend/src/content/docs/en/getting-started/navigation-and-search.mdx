## Primary navigation

The left sidebar is the main way to move across the workspace. It exposes the main product areas:

- Dashboard
- Projects
- Board
- Calendar
- Gantt
- Metrics
- Flows
- Timesheet
- Docs
- Settings

Additional team and admin surfaces appear under the lower navigation groups when your role allows them.

## Project context

Some pages operate globally, while others depend on an active project. Board and Flows, for example, switch context based on the selected project or query parameter in the URL.

When a page shows a project switcher, make sure you are working in the intended project before editing tasks or rules.

## Header actions

The top header gives quick access to:

- global search
- notifications
- refresh state
- sync status

The header also reflects the current page context so you can tell whether you are in a workspace-level screen or a project-specific screen.

## Global search

The search modal is designed for fast movement, not just discovery. It can surface:

- application pages
- tasks
- projects
- users

Use it when you already know roughly what you need and want to jump there without browsing multiple screens.

## Notification-driven navigation

The notification bell links back into the product. Depending on the event, a notification can take you directly to related task work, approvals, or other operational context.

## Recommended habits

- keep the sidebar open on desktop if you switch contexts often
- use search when you know the task or project name
- use notifications as an action queue, not just a passive inbox
- confirm project context before bulk editing or running flows
