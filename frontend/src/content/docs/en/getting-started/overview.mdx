## What Era Kanban is built for

Era Kanban is a single workspace for planning, executing, reviewing, and measuring project work. The product combines:

- projects for structure and ownership
- board for day-to-day execution
- calendar and Gantt for date-based planning
- rule-based automations and visual flows for repeatable work
- portal for external review and approvals
- metrics, notifications, and timesheets for follow-through

## Core navigation model

Most teams move through the product in a simple loop:

1. Create a project and invite the right people.
2. Define columns that match the real workflow.
3. Create and assign tasks from the board.
4. Add due dates and validate the schedule in Calendar or Gantt.
5. Reduce repetitive work with automations or flows.
6. Use Portal when outside stakeholders need to review work.
7. Track delivery with metrics, notifications, and timesheets.

## Main screens and what they do

### Projects

Projects define the workspace boundary for columns, tasks, members, and integrations.

### Board

Board is the main operational surface. This is where teams create tasks, move work between statuses, and collaborate on details.

### Calendar

Calendar helps teams understand due dates in month and week layouts and add dated work quickly.

### Gantt

Gantt gives a longer planning horizon with zoom, grouping, and date adjustment directly on the timeline.

### Automations and Flows

Automations handle focused workflow rules inside a project. Flows provide a more visual builder with trigger, condition, and action nodes.

### Portal

Portal allows non-dashboard reviewers to leave comments, approve deliverables, or request revisions.

## How permissions usually work

- owners and admins manage project structure, members, and settings
- members work with tasks and collaboration features
- viewers are limited to read-oriented access where supported
- only admins can access the global admin console
